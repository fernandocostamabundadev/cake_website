# Delizia

Website responsivo de bolos artesanais, desenvolvido com HTML, CSS e JavaScript.

## Funcionalidades

- Conteúdo em português de Portugal e apresentação adaptada a telemóveis.
- Navegação acessível por teclado, incluindo fecho do menu com `Escape`.
- Filtros de bolos, contador demonstrativo de encomendas e formulário de contacto local.
- Animações de entrada e de interação que respeitam a preferência por movimento reduzido.

## Utilização

Abra `index.html` num navegador. O formulário e o contador são demonstrações locais: não enviam encomendas nem recolhem dados pessoais.

Projeto inspirado no tutorial [Responsive Cake Website](https://youtu.be/G6q7AkaljE4), de [Bedimcode](https://www.youtube.com/@Bedimcode).
